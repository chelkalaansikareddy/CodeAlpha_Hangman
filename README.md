# 🎮 CodeAlpha Hangman Game

A simple **text-based Hangman game** developed using **Python** as part of the **CodeAlpha Python Programming Internship**.

The game randomly selects a word from a predefined list, and the player has to guess the word one letter at a time. The player can make a maximum of **6 incorrect guesses** before the game ends.

---

## 📌 About the Project

This project was created to practice fundamental Python programming concepts through a small interactive console application.

The game demonstrates how Python can be used to handle:

* 🎲 Random word selection
* ⌨️ User input
* 🔄 Loops
* 🔀 Conditional statements
* 📝 Strings and lists
* ✅ Input validation
* 🎯 Game logic

---

## ✨ Features

* 🎯 **5 predefined words**
* 🎲 **Random word selection**
* 🔤 **Letter-by-letter guessing**
* ❤️ **Maximum 6 incorrect guesses**
* ✅ **Input validation**
* 🔄 **Prevents repeated guesses**
* 📊 **Displays guessed letters**
* ⏳ **Shows remaining attempts**
* 🏆 **Win condition**
* ❌ **Game-over condition**
* 💡 **Reveals the word when the player loses**
